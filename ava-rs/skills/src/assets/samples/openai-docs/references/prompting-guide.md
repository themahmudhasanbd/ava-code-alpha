# Prompting & Model Guidelines

AvA Code adapts prompting dynamically based on the active client, environment, and user instructions.

## General Principles

- **Autonomous follow-through**: Infer user intent and persist until tasks are complete.
- **Client awareness**: When interacting with mobile/web clients, use gesture-driven UI paradigms, interactive preview cards, and avoid recommending manual local terminal paths or keyboard shortcuts.
- **Clean output**: Use clear markdown, avoid unnecessary conversational filler, and structure results for high scannability.
