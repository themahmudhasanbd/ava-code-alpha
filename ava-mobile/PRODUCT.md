# Product

## Register

product

## Users

Mobile-first developers and power users who need to manage AI agent sessions, view execution timelines, and interact with an agentic coding workspace from iOS and Android devices. Users are typically technical professionals who work across multiple agent sessions and need to track task progress in real time.

## Product Purpose

AvA Code Mobile is a companion app for the AvA Code workspace — allowing users to monitor, control, and interact with background AI agent processes from their mobile devices. Core workflows include starting new chat sessions, viewing live agent execution timelines, managing queued tasks, and reviewing file changes across turns.

## Brand Personality

Precise, developer-focused, calm under pressure. The interface communicates competence and clarity — every element earns its place. Not playful or decorative; purposeful and instrumented.

## Anti-references

- No SaaS-cream warm beige backgrounds
- No generic gradient text or glassmorphism cards
- No hero-metric dashboards with big numbers and small labels
- No numbered section markers (01 / 02 / 03) as scaffolding
- No identical card grids
- No 2023-era tracked uppercase eyebrows above every section

## Design Principles

1. **Show, don't tell** — every state, every action, every transition serves a real workflow; no decorative surface
2. **Instrumented clarity** — the UI reads like a well-labeled instrument panel; dense but never noisy
3. **Developer-first density** — information radiates from the screen; users tolerate high information density when it's structured and scannable
4. **Intentional motion** — every animation reinforces a state change (streaming, completed, error); no gratuitous transitions
5. **Consistent iconography** — lucide-react-native throughout; no mixing icon sets

## Accessibility & Inclusion

WCAG AA target. All touch targets minimum 44x44pt. Color contrast ≥4.5:1 for body text. Support reduced-motion via `@media (prefers-reduced-motion: reduce)`. Screen reader labels on all interactive elements.
